<h2>📖 Sobre o Projeto</h2>

<p>
Esta aplicação simula uma Pokédex utilizando Python e os conceitos de
Programação Orientada a Objetos. O sistema realiza consultas em tempo real
à PokéAPI, permitindo obter informações detalhadas dos Pokémons através
de seu nome ou ID.
</p>

<p>
Além da consulta, os Pokémons podem ser armazenados durante a execução
do programa para posterior visualização e gerenciamento.
</p>

<hr>

<h2>⚙️ Funcionalidades</h2>

<ul>
  <li>Consultar Pokémon por nome ou ID</li>
  <li>Cadastrar Pokémons na Pokédex</li>
  <li>Listar Pokémons cadastrados</li>
  <li>Exibir informações detalhadas</li>
  <li>Mostrar imagem oficial do Pokémon</li>
  <li>Exibir quantidade total de Pokémons cadastrados</li>
  <li>Navegação através de menu interativo</li>
</ul>

<h2>🚀 Instalação</h2>

<h3>1. Clone o repositório</h3>

<pre>
git clone https://github.com/AllanaMrtins/Pokedex-com-Menu.git
</pre>

<h3>2. Acesse a pasta do projeto</h3>

<pre>
cd Pokedex-com-Menu
</pre>

<h3>3. Instale as dependências</h3>

<pre>
pip install -r requirements.txt
</pre>

<hr>

<h2>▶️ Execução</h2>

<pre>
python main.py
</pre>
